# File format lookup

Maps file extensions to a Format name and typical producing software / file
specification, for filling the **Data Records** format table. Mined from the
EBRAINS data descriptor corpus (counts = number of descriptors using the
extension). Use the Format and Software columns as defaults; always confirm the
producing software with the user, and expand the third column with the file's
schema, units, and naming conventions (see `reference/data-records-guide.md`).

| Extension | Format name | Typical software / specification |
|-----------|-------------|----------------------------------|
| `.nii`, `.nii.gz` | (Gzipped) NIfTI-1 Image | Neuroimaging volume; often BIDS-organised |
| `.bval` | B-values | Diffusion gradient b-values; part of BIDS |
| `.bvec` | B-vectors | Diffusion gradient directions; part of BIDS |
| `.tsv` | Tab-Separated Values | BIDS metadata / events; or self made |
| `.csv` | Comma-Separated Values | Tabular data; often generated by analysis script |
| `.json` | JavaScript Object Notation | BIDS sidecar / metadata; or self made schema |
| `.mat` | MATLAB data file | Generated by MATLAB (state version, e.g. R2021a). If any variable is a MATLAB `string`, say so: SciPy cannot read it, and only a tested reader is recommended |
| `.npz` | NumPy compressed archive | Generated by Python/NumPy |
| `.h5`, `.hdf5` | Hierarchical Data Format 5 | HDF5; document internal groups/datasets |
| `.nwb` | Neurodata Without Borders | NWB; state the schema version and the writer. For every series give the declared `unit` and the `conversion`; PyNWB applies it in `get_data_in_units()`, MatNWB's `load()` returns stored values. Run `nwbinspector` and report its critical messages |
| `.smr` | Spike2 data file | CED Spike2 electrophysiology recording |
| `.set`, `.fdt` | EEGLAB dataset | EEGLAB (MATLAB); `.set` header + `.fdt` data |
| `.eeg`, `.vhdr` | BrainVision recording | BrainVision; `.vhdr` header + `.eeg` data |
| `.edf` | European Data Format | Biosignal recording |
| `.czi` | Carl Zeiss Image | Generated by Zeiss Axioscan / ZEN software |
| `.tif`, `.tiff`, `.ome.tiff` | Tagged Image File Format | Microscopy image; state pixel size & units |
| `.qpproj` | QuPath Project | Generated by QuPath |
| `.qpdata` | QuPath data | QuPath, Java-serialised; read only in QuPath |
| `.png`, `.jpg`, `.jpeg` | Raster image | Figures / thumbnails / plots |
| `.svg` | Scalable Vector Graphics | Vector figure |
| `.xlsx`, `.xls` | Microsoft Excel Workbook | Tabular data; state sheet/column scheme |
| `.txt` | Plain / Tab-Separated text | Self made; state column scheme if tabular |
| `.yml`, `.yaml` | YAML Ain't Markup Language | Self made config (e.g. analysis parameters) |
| `.xml` | Extensible Markup Language | Metadata / annotations |
| `.zip` | ZIP compressed archive | State contents and producing tool |
| `.pdf` | Portable Document Format | EBRAINS data descriptor (this file); license |
| `.docx` | Microsoft Word Document | Documentation |
| `.m` | MATLAB script/function | Analysis code (MathWorks MATLAB) |
| `.py` | Python script | Analysis code |
| `.ipynb` | Jupyter Notebook | Analysis notebook |
| `.r` | R script | Analysis code |
| `.parquet` | Apache Parquet | Columnar tabular data |
| `.avi`, `.mp4` | Video | State codec, frame rate, resolution |
| `.wav` | Waveform Audio | Audio stimulus / recording |
| `.abf` | Axon Binary Format | pCLAMP / Clampex; state the protocol per file kind and the sampling rate |
| `.ibw`, `.pxp` | Igor Binary Wave / Packed Experiment | Igor Pro; check the wave's unit label against the magnitude of its values |
| `.ntt`, `.ncs`, `.nvt` | Neuralynx spike / continuous / video tracking | Neuralynx Cheetah |
| `.t64`, `.t` | MClust spike times | MClust; a text header followed by binary timestamps, not a MAT-file; state the integer width and byte order |
| `.pkl` | Python pickle | Readable only with the library versions that wrote it; state them exactly, and prefer a neutral export |
| `.dat`, `.bin`, `.raw` | Binary data | Custom binary; document layout & dtype |
| `.obj` | Wavefront OBJ | 3D mesh / geometry |

For an extension not listed here, ask the user for the format name and producing
software, and add a row.

Two notes that apply across formats. **Compress.** HDF5 and NWB files are often
deposited uncompressed; `gzip` level 4 inside HDF5 typically removes about 30% of
the bytes with no change in content, and every reuser downloads the difference.
**State the stored unit, not only the declared one.** A reader that takes the
raw array without the conversion gets a plausible number in the wrong unit.
